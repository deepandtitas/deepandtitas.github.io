# AGENTS.md — Deep & Titas · শুভ পরিণয়

Interactive Bengali wedding invitation. A Remotion composition (1080×1920, 30 FPS, 1500 frames) is played
inside a mobile-first React shell via `@remotion/player`, and ends on an interactive invitation card.

## Commands
- `npm run dev` — Vite dev server for the website
- `npm run studio` — Remotion Studio (composition id `DeepAndTitasWedding`)
- `npm run render` — render the full MP4 to `out/`
- `npm run still` — render the final invitation frame to `out/invitation.png`
- `npm run typecheck`, `npm run lint`, `npm test`, `npm run build`

## Architecture
- `src/config/` — `timeline.ts` (single source of truth for frames), `wedding.ts` (editable event details),
  `translations.ts` (bn/en dictionary), `assets.ts` (asset URL helper)
- `src/remotion/` — the cinematic composition (scenes, ornaments, character rig, the invitation card). Registered in `index.ts`/`Root.tsx`.
- `src/app/` — the website shell (intro, controls, guided-mode state machine in `state/storyMachine.ts`, language toggle)
- `public/` — local images (generated by `scripts/generate-art.mjs`) and the optional `audio/soundtrack.mp3`
- `tests/` — Vitest unit tests (timeline, translations, wedding config, story machine)

## Verifying visual changes
`node scripts/stills.mjs <frames…>` renders PNGs to `out/stills/` (add `--lang=en`). Look at them — key frames:
0, 150, 239 (scene 1), 420, 569 (scene 2), 820, 960, 1049 (scene 3), 1100, 1499 (invitation).

## Rules
1. **Frame-driven only.** All cinematic animation derives from `useCurrentFrame()` with `interpolate()`/`spring()`.
   No `setTimeout`, CSS animation timers or wall-clock time inside `src/remotion/`. The same frame must render identically twice.
2. **Timeline is the single source of truth.** Scene starts/ends, guided checkpoints, the skip target and the
   composition duration are all imported from `src/config/timeline.ts`. Never hard-code frame numbers elsewhere.
   A 1500-frame composition has last frame index 1499.
3. **No `import.meta.env` inside `src/remotion/`** (Remotion Studio bundles with webpack). Pass values in via `inputProps`.
4. **Asset URLs** go through `asset()` in `src/config/assets.ts` using the `assetBase` input prop, so the site works under
   a sub-path if one is ever needed (`BASE_PATH`). Production is the GitHub user site `https://deepandtitas.github.io/` at the root.
5. **Never fabricate wedding details.** Date, time, venue name and address stay blank in `wedding.ts` until the family provides them;
   blank fields are hidden (or shown as clearly marked placeholders in dev only). Never alter or round the map coordinates.
6. **Character consistency.** Deep and Titas are drawn only by the shared rig in `src/remotion/components/WeddingCouple.tsx`.
7. **Cultural respect.** Bengali sequence: শুভদৃষ্টি, then মালাবদল. Do not add rituals that are not clearly depicted correctly
   (no fire ritual or sindoor daan). When unsure, use a symbolic depiction.
8. **Audio** is optional and starts only after a user gesture; a missing track must degrade silently.
9. Keep website interaction state (React) separate from frame-driven state (Remotion). Do not re-render the shell per frame.
10. Bengali is the default language; every visible string comes from `translations.ts`.
11. Decorative composition layers must stay click-through (`pointer-events: none` on the composition root);
    only hotspot buttons and the map link opt back in. Guided-mode boundary checks use `>=` and run before scene updates,
    because the Player can skip frames on slow devices.
